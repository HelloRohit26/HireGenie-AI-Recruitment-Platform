📌 POST OPTION 2: TECHNICAL DEEP-DIVE (FOR TECH LEADS, CTOS & ENGINEERS)
(Best for showcasing software engineering depth, architecture, and system design)
================================================================================

🚀 Excited to unveil HireGenie AI (TalentOS): An Autonomous Multi-Agent Recruitment & Talent Intelligence Platform.

Building this challenged me to solve some tough real-time engineering problems across audio streaming, deterministic AI evaluations, and asynchronous job queues.

Key Architectural Innovations:

1. Sub-Second Conversational Voice AI with Sarvam AI:
Instead of standard text chat or clunky push-to-talk widgets, HireGenie embeds Sarvam Conversational Voice AI directly into the interview cockpit. It streams bidirectional WebRTC audio, allowing sub-second natural dialogues tailored for Indian tech talent.

2. Deterministic Resume Screening & Skill Normalization:
Variations like "React", "React.js", and "ReactJS" break standard regex parsers. We implemented an ontology-driven canonical skill normalizer coupled with LLM reasoning to evaluate applicants against strict, reproducible rubrics.

3. Parallelized Async Worker Queue:
Heavy tasks (PDF parsing, multi-criteria screening, email dispatch, transcript evaluation) run asynchronously on Celery workers backed by Redis, ensuring sub-100ms API response times.

4. Unified Split-Screen Cockpit:
Built with React 18 + Vite, featuring a live multi-language code sandbox, real-time waveform visualizers, webcam proctoring, and turn-by-turn speech transcription.

5. Fairness & Trust Guardrails:
Integrated automated Disparate Impact Ratio (4/5ths rule) calculations to track and eliminate demographic bias across hiring funnels.
